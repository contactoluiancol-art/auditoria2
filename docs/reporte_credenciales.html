Inventario de Servicios, Credenciales y Guía de Despliegue

Proyecto: ERP Auditoría & Logística
Fecha: 26 de Agosto, 2026
Estado: Listo para Producción

Estimado equipo de infraestructura, he finalizado la refactorización y migración técnica del ERP, desacoplando completamente el sistema de Vercel y centralizando el consumo de servicios en Supabase. A continuación, detallo el inventario exhaustivo de servicios, la clasificación de credenciales, las variables de entorno necesarias en el servidor y las directivas de seguridad para el despliegue.

1. Inventario de Servicios y Arquitectura

Servicio Función en el Sistema Estado en Despliegue Configuración Necesaria
Vercel Hosting frontend original Reemplazado Se elimina. Ya no existen dependencias de su plataforma.
Nuevo Hosting Servidor web estático (HTML/JS/CSS) Producción Directorio raíz público (public_html / Nginx) con SSL/HTTPS activo.
Supabase PostgreSQL Base de datos relacional y Auth Activo Esquema ejecutado (scripts 001 a 006) y RLS habilitado en todas las tablas.
Supabase Storage Almacenamiento de actas y evidencias Activo Buckets configurados: recepciones-pdf y auditorias.
Supabase Realtime Sincronización en vivo vía WebSockets Activo Publicación activa para tablas de recepciones, auditorías y usuarios.

2. Inventario y Clasificación de Credenciales

Credencial / Variable Servicio Asociado Ámbito Nivel de Permisos Requerido
SUPABASE_ANON_KEY Supabase API & Auth Frontend Permisos CRUD restringidos a nivel de fila por políticas RLS activas.
SUPABASE_SERVICE_ROLE Supabase Backend / Admin Estrictamente Privada Superusuario (Bypass RLS). No debe exponerse en el cliente.
POSTGRES_URL Motor PostgreSQL Infraestructura Conexión directa puerto 5432/6543 para migraciones y mantenimiento.
Usuario Administrador Acceso Interfaz ERP Operacional Rol admin con permisos totales en todos los módulos operativos.

3. Credenciales que Deben Regenerarse

Para asegurar el cumplimiento de las buenas prácticas de seguridad en el pase a producción, he definido las siguientes acciones:

  • Contraseña de usuario administrador: He provisionado la cuenta inicial con el usuario admin y contraseña temporal admin123. Esta debe cambiarse inmediatamente en el primer inicio de sesión desde el módulo de Usuarios.
  • Rotación de llaves API (Opcional): Si el repositorio estuvo temporalmente expuesto, recomiendo ingresar a Supabase Dashboard > Settings > API y generar un nuevo par de claves anon y service_role.
  • Contraseña del usuario postgres: Actualizar la contraseña de la base de datos en Supabase para evitar accesos administrativos directos no autorizados.

5. Directivas de Seguridad y Servidor Web

Parámetros para la configuración de Nginx / Apache:
  • HTTPS Obligatorio: Redirección de todo el tráfico HTTP a HTTPS mediante certificado SSL válido.
  • Content Security Policy (CSP): Permitir conexiones únicamente hacia los dominios autorizados: https://hurxdjoiafkjoyrmyhbd.supabase.co y wss://hurxdjoiafkjoyrmyhbd.supabase.co.
  • Cabeceras de Protección: Activar X-Frame-Options: SAMEORIGIN y X-Content-Type-Options: nosniff.
